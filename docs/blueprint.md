# **App Name**: Design Muse

## Core Features:

- Prompt Input: Accepts user's description of desired website or app.
- Color Palette Suggestion: Generates color palettes based on the prompt and explains the emotion each color evokes. Output will show a visual scale of colors, and give each its hexcode.
- Typography Suggestions: Suggests font pairings based on user's description, providing options for headlines and body text, explaining when to use them. The AI tool will also intelligently adapt suggested type sizes to the target platform and content types described by the user.
- Layout and Spacing: Offers suggestions for layout and spacing based on platform (mobile, web) and content type (e.g., blog, e-commerce).
- Inspiration Gallery: Displays design examples related to the user's prompt for visual inspiration.
- Export Styles: Allow users to copy CSS styles or export the generated guidelines in a document.

## Style Guidelines:

- Primary color: A muted teal (#70A1A9). The choice of teal suggests trustworthiness and tranquility, ensuring that new designers don't feel intimidated.
- Background color: A light off-white (#F4F5F0). The subtle contrast will minimize distractions.
- Accent color: Soft coral (#E9927D). A balanced choice relative to teal, which still helps the interface feel calming rather than jarring.
- Headline font: 'Belleza' (sans-serif) for headlines and shorter text snippets.
- Body font: 'Alegreya' (serif) for body text and longer text passages.
- Use simple, geometric icons to maintain a modern and clean interface.
- Maintain generous white space to ensure readability and focus. Base mobile sizes around an 8dp grid.
- Use subtle animations on transitions and interactions to enhance the user experience.
